# Hawaii Pig Carcass Decomposition - Soil Biogeochemistry & Biolog EcoPlate Dataset

This repository contains the dataset and documentation from the study:
> **"Biogeochemical evaluation of soils impacted by pig carcass decomposition in a Hawaiian tropical savanna ecosystem"**
> *Emily Leanna Pecsi, François Guillemette, Shari Forbes, Hugo Germain, David Carter, Mélodie B Plourde, Théo Devèze (2026).*
> DOI: [10.5683/SP4/UXYJGA](https://doi.org/10.5683/SP4/UXYJGA)

---

## 📂 Repository Contents

- `Pecsi_Hawaii_Biogeochem_PigDecomposition.csv`: Biogeochemical soil measurements (BA, BR, DOC, optical indices, PARAFAC components).
- `Pecsi_Hawaii_Biogeochem_PigDecomposition_ReadMe.txt`: Metadata, methodology, and variable dictionary for the biogeochemical dataset.
- `Pecsi_Hawaii_Biolog_PigDecomposition.csv`: Biolog EcoPlate carbon substrate utilization profiles (AWCD).
- `Pecsi_Hawaii_Biolog_PigDecomposition_ReadMe.txt`: Metadata, methodology, and variable dictionary for the Biolog EcoPlate dataset.
- `MANIFEST.TXT`: File manifest and checksum hashes.

---

## 🔬 Dataset Overview

- **Location:** Hawaiian tropical savanna ecosystem (21.290833 N, -157.804722 W).
- **Soil Type:** Silty clay soil (Pamoa soil series).
- **Experimental Design:** Surface deposition of 40 kg pig carcasses ($n=3$) monitored across decomposition phases and distances from carcass.
